Разбиение ТЗ на Эпики и Таски для ИИ агента
Эпик 1: Проектирование и разработка алгоритмов поиска Эйлерова пути

Цель: Реализовать два алгоритма поиска Эйлерова пути в неориентированном графе.

Задачи:

Реализация алгоритма Хиерхольцера:

Реализовать алгоритм с использованием глубинного поиска для нахождения Эйлерова пути.

Применить рекурсию для возврата к предыдущим вершинам, если путь заблокирован.

Инструмент: Python, библиотека networkx.

Реализация алгоритма Флёри:

Реализовать алгоритм, который пошагово использует рёбра для поиска Эйлерова пути.

Обрабатывать графы с неудачным соединением рёбер и искать обход.

Инструмент: Python, библиотека networkx.

Эпик 2: Проектирование пользовательского интерфейса для загрузки данных и вывода результатов

Цель: Разработать интерфейс, который позволяет пользователю вводить данные вручную или загружать их через JSON.

Задачи:

Разработка интерфейса для ввода данных вручную:

Реализовать ввод данных о графе (вершины и рёбра) через консоль.

Обеспечить валидацию введённых данных.

Инструмент: Python.

Разработка интерфейса для загрузки данных через JSON:

Реализовать загрузку данных из JSON-файла.

Приложение должно поддерживать произвольные размеры файлов.

Инструмент: Python, библиотека json.

Вывод результатов в консоль и файл:

Результаты поиска Эйлерова пути должны быть выведены в консоль и записаны в файл в формате JSON.

Инструмент: Python, библиотека json.

Эпик 3: Модульное тестирование алгоритмов по принципам TDD

Цель: Разработать и провести тестирование для каждого из алгоритмов с использованием принципов TDD.

Задачи:

Написание модульных тестов для алгоритма Хиерхольцера:

Написать тесты для проверки корректности работы алгоритма.

Проверить на разных типах графов.

Инструмент: PyTest.

Написание модульных тестов для алгоритма Флёри:

Написать тесты для алгоритма Флёри.

Проверить алгоритм на различных типах графов.

Инструмент: PyTest.

Эпик 4: Проектирование тестов с использованием различных техник

Цель: Применить различные методы проектирования тестов, включая Boundary Value Analysis и Branch Testing.

Задачи:

Проектирование тестов с использованием Boundary Value Analysis:

Протестировать алгоритмы с использованием предельных значений данных.

Инструмент: PyTest.

Проектирование тестов с использованием Branch Testing:

Проверить все возможные ветви алгоритмов.

Инструмент: PyTest.

Эпик 5: Мутационное тестирование

Цель: Применить мутационное тестирование для проверки качества тестов.

Задачи:

Применение мутационного тестирования:

Применить Pitest или MutPy для тестирования.

Оценить, насколько тесты могут выявить мутации в коде.

Инструмент: Pitest или MutPy.
